# Tests Directory

This directory contains all test files for the Memory Agent project.

## Purpose

- Organize testing files in a structured manner
- Provide comprehensive test coverage for the Memory Agent functionality
- Support continuous integration and quality assurance processes

## Directory Structure

- `unit_tests/`: Contains isolated tests for individual components and functions
- `integration_tests/`: Contains tests that verify the integration between components
- Additional test categories may be added as the project evolves

## Guidelines

- Use pytest as the primary testing framework
- Follow the testing conventions outlined in copilot-test-instructions.md
- Ensure all new features have corresponding test coverage
- Tests should be isolated and not depend on external services where possible
